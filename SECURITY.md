# Security and data-privacy policy

This repository is intended for research image analysis and may be used with sensitive specimens. Public issues and pull requests must not contain protected health information, identifiable labels, patient or animal identifiers, institutional paths, or raw clinical images.

Report suspected code-execution, dependency, or data-disclosure issues privately to the repository maintainer. Until a maintainer address is configured, do not post sensitive details publicly; open a minimal issue requesting a private contact channel.
