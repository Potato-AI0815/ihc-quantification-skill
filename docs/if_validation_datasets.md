# Public Bioimage Validation Datasets and Benchmarks

## Benchmark Repositories and Recommended Datasets

### 1. Broad Bioimage Benchmark Collection (BBBC)
- **[BBBC006](https://data.broadinstitute.org/bbbc/BBBC006/)**: Human U2OS cells (Hoechst nuclear + Phalloidin cytoplasm). Ideal for nuclear/cytoplasm 2-channel validation.
- **[BBBC039](https://data.broadinstitute.org/bbbc/BBBC039/)**: 200 high-resolution fluorescence images with manual ground-truth segmentation masks for computing Dice, IoU, and F1 metrics.
- **[BBBC022](https://data.broadinstitute.org/bbbc/BBBC022/)**: Cell Painting 5-channel high-content profiling assay.

### 2. Human Protein Atlas (HPA)
- [Human Protein Atlas Subcellular Section](https://www.proteinatlas.org/): 4-channel confocal immunofluorescence (Nucleus / Target / Microtubules / ER).

### 3. BioImage Archive (EMBL-EBI) & IDR
- [BioImage Archive](https://www.ebi.ac.uk/bioimage-archive/): Open repository for biological imaging data.
- [Image Data Resource (IDR)](https://idr.openmicroscopy.org/): Peer-reviewed imaging datasets with full experimental metadata.

### 4. Harvard Tissue Atlas (t-CyCIF)
- [Tissue Atlas](https://tissueatlas.hms.harvard.edu/): Multiplexed cyclic immunofluorescence datasets for spatial single-cell tissue architecture.
